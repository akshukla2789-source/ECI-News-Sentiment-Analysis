# ECI News Sentiment Analysis

## Project Overview
This project analyzes Election Commission of India (ECI) related news using Python, Natural Language Processing (NLP), and sentiment analysis.

## Objectives
- Collect ECI-related news articles.
- Process and clean textual data.
- Analyze positive, negative, and neutral sentiments.
- Apply machine learning techniques to news classification.

## Technologies Used
- Python
- Google Colab
- NewsAPI
- Pandas
- NumPy
- NLTK (VADER)
- Scikit-learn
- Matplotlib

## How to Run
1. Open `ECI.ipynb` in Google Colab.
2. Configure your NewsAPI key using Colab Secrets.
3. Run the notebook cells.
4. Analyze the sentiment results.
